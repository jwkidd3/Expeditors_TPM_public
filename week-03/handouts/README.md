# Week 3 Handouts — Requirements Engineering & PRD Mini-Capstone

Participant-facing handouts for Week 3. Each is a standalone template, card, pack, or checklist — distribute (print or share) before the day and activity that uses it. Templates are meant to be filled in; the triage-pack answer keys stay in the facilitator lab files, not here.

| Handout | Day · Activity | What it is |
|---|---|---|
| `prd-template` | Day 1 · A1 | 11-section PRD skeleton with `[Day X]` tags + section-relationship notes |
| `week-2-feature-cards` | Day 1 · A1 | Three FieldPulse feature cards to score and choose from |
| `four-dimension-scoring-sheet` | Day 1 · A1 | Fillable 1–5 scoring grid + tie-break + locked-pick fields |
| `why-this-one-memo-template` | Day 1 · A2 | Two-paragraph (user / business) memo that seeds PRD §1 |
| `section-5-inclusion-exclusion-checklist` | Day 1 · A3 | §5 in/out checklist + the "engineer's first three questions" test |
| `ac-failure-mode-checklist` | Day 2 | The 5 AC failure modes + happy/sad/weird coverage + pass/fail sheet |
| `ac-triage-pack` | Day 2 · A1 | 12 acceptance-criteria examples to triage — no labels provided |
| `ac-template-card` | Day 2 · A2 | Given/When/Then pocket card + worked example + blank cards |
| `sad-weird-path-generator-prompts` | Day 2 · A3 | Sad/weird-path generator prompts + worked examples + worksheet |
| `ac-cross-review-template` | Day 2 · A4 | Reviewer worksheet + §6 review-resolution note |
| `nfr-template-card` | Day 3 · A2 | Four-part NFR shape, the 5 categories, worked example, self-check |
| `nfr-failure-mode-checklist` | Day 3 | The 5 NFR failure modes + triage pass/fail sheet |
| `nfr-triage-pack` | Day 3 · A1 | 10 NFR examples to triage — no labels provided |
| `nfr-cross-review-template` | Day 3 · A3 | Four classic trade-offs + reviewer worksheet + "known trade-offs" |
| `section-8-11-templates` | Day 4 · A1 | Fillable §8/§9/§10/§11 templates with guardrail notes |
| `integration-checklist` | Day 4 · A2 | Eight-item integration check + AI-prose tell list + lock confirmation |
| `friday-review-rubric` | Day 5 | Six weighted review dimensions + worked scoring + verdict bands |
| `review-document-template` | Day 5 · A1 | Primary review deliverable (scores, 3 strengths, 5 findings, open qs) |
| `review-resolution-log-template` | Day 5 · A2 | Adopt/defer/push-back log + status flip |
| `secondary-review-note-template` | Day 5 · A3 | Secondary reviewer note with verdict checkboxes + honesty-check |

**Design principle:** these are working surfaces, not narration. The AC and NFR triage packs are deliberately spoiler-free — the judging is the work.
