# Week 6 Handouts — Stakeholder Alignment & Negotiation

Participant-facing handouts for Week 6. Each is a standalone grid, template, card pack, or rubric — distribute (print or share) before the day and activity that uses it. Role-play cards have a **Public surface** everyone may read and a **Hidden** section only the roleplayer sees; keep the Hidden sections out of the other triad's hands.

| Handout | Day · Activity | What it is |
|---|---|---|
| `power-interest-grid` | Day 1 · A1 | 2×2 Power × Interest grid + quadrant engagement styles + worked example |
| `raci-matrix-template` | Day 1 · A2 | R/A/C/I definitions + 5-decision matrix template + 4 checks |
| `engagement-style-table` | Day 2 | Four engagement principles + cadence/format/length by quadrant |
| `engagement-plan-template` | Day 2 · A2 | Per-stakeholder engagement-plan block + asks categories + anti-patterns |
| `engagement-triage-pack` | Day 2 · A1 | 8 stakeholder profile cards (Public + Hidden); 2 are traps |
| `translation-drill-pack` | Day 3 · A1 | 6 technical statements paired to a stakeholder + worksheet |
| `trade-off-brief-template` | Day 3 · A2 | One-page trade-off brief template + translation table + worked example |
| `objection-map-template` | Day 4 | Per-objection template (response / pivot / line held) + non-negotiables |
| `opening-template` | Day 4 | 60-second 4-part opening + worked example + rehearsal checklist |
| `surprise-objection-set` | Day 5 · Round 1 | 2 surprise objections each for Architect / Security / Eng Director |
| `scope-creep-ask-cards` | Day 5 · Round 2 | 3 scope-creep asks with hidden real-driver + fallback |
| `executive-demand-scenario-cards` | Day 5 · Round 3 | 3 executive demands with hidden settle points |
| `negotiation-rubric` | Day 5 | 6-dimension scoring rubric + round structure + trade-space concept |
| `negotiation-score-sheet` | Day 5 | Printable weighted score sheet + quick-tally version |
| `outcomes-log-template` | Day 5 | SEP §5 per-round outcomes-log block + three-round overview |

**Design principle:** these are working surfaces, not narration. Role-play cards keep their real driver / settle point in the Hidden section — the author has to surface it through good questions.
