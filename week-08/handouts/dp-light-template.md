# DP-Light Template (1 page)

> **Day 4 handout.** The compressed Delivery Plan — Week-7 work in ~20 minutes. Outcome map + backlog skeleton + tracking plan + value stream + one bottleneck experiment. The primary outcome must be **user-visible**; leading indicators must be **measurable within 7 days**.

---

```markdown
# DP-light — <feature>

## 1. Outcome map (compressed)
Primary outcome + 2 supporting outcomes + 1 counter-outcome.

## 2. Backlog skeleton
1 Epic + 1 Feature + 5 User Stories (top-priority subset of PRD-light §6).

## 3. Tracking plan (compressed)
3 leading indicators. 1 monthly review cadence.

## 4. Value stream (compressed)
Top 3 queues identified.

## 5. 1 Bottleneck removal experiment
Hypothesis / test / success criterion for one queue.
```

---

### Build order (20 min)
1. **5 min** — outcome map (primary + 2 supporting + 1 counter).
2. **5 min** — backlog skeleton.
3. **5 min** — 3 leading indicators.
4. **5 min** — 1 bottleneck experiment.

### What "good" looks like
- The primary outcome is **user-visible**, not an internal output.
- The 5 user stories are the **top-priority subset** of PRD-light §6, not a re-listing.
- Leading indicators are **measurable within 7 days**.
- The bottleneck experiment has a **measurable success criterion** — hypothesis, test, and what "worked" looks like.
