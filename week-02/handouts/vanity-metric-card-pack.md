# Vanity-Metric Card Pack

> **Day 1 · Activity 1 handout.** Twelve metrics drawn from FieldPulse-adjacent SaaS products. Sort them, then bet on two and refuse to report two — the argument is the point.

Cut these into cards, or work them as a list. For each card, place it on the 2×2, then pick the two you would **bet on** for FieldPulse and the two you would **never report up**. One-sentence rationale per pick.

## The 2×2

```
                Easy to game
                    |
                    |
Lagging  -----------+----------- Leading
                    |
                    |
                Hard to game
```

## The cards

| # | Metric |
|---|--------|
| 1 | Daily Active Users |
| 2 | Number of features shipped per quarter |
| 3 | Average session length |
| 4 | % of dispatchers who completed onboarding |
| 5 | Support tickets closed per agent per day |
| 6 | Mean time to first dispatch after login |
| 7 | Reconcile-flow completion rate |
| 8 | New trial sign-ups per week |
| 9 | Push notifications sent per day |
| 10 | Average dispatcher rating in the app store |
| 11 | Median time to close out an end-of-day reconcile |
| 12 | % of jobs closed same-day (worked and fully reconciled) |

---

### Deliverable

A sorted 2×2 with your **bet-on** and **never-report-up** cards labeled, plus one sentence of rationale per pick, rooted in the causal chain:

> "We would bet on **[X]** and **[Y]** because [reason]. We would never report up **[A]** or **[B]** because [reason]."
