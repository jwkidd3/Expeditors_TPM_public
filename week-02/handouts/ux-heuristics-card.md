# UX Heuristics Card

> **Day 3 · reference handout.** The shared vocabulary for every UX audit this week: Nielsen's 10 heuristics plus three TPM-specific lenses. Name the heuristic number when you flag a violation.

## Nielsen's 10 (abbreviated)

1. **Visibility of system status** — the product keeps users informed about what's going on.
2. **Match between system and real world** — speaks the user's language, not internal jargon.
3. **User control and freedom** — an easy exit / undo from mistakes.
4. **Consistency and standards** — same words and actions mean the same thing throughout.
5. **Error prevention** — design that stops problems before they happen.
6. **Recognition rather than recall** — options are visible; users don't have to remember.
7. **Flexibility and efficiency of use** — accelerators for experts, still usable by novices.
8. **Aesthetic and minimalist design** — no irrelevant information competing for attention.
9. **Help users recognize, diagnose, and recover from errors** — plain-language errors that suggest a fix.
10. **Help and documentation** — findable, task-focused help when needed.

## TPM-specific lenses (added today)

11. **Time-to-first-value** — can a new user produce a useful result in their first session?
12. **Failure-mode dignity** — how does the product behave when the network drops, the data is wrong, or the user is rushed?
13. **Power-user respect** — does the product reward repeat use with shortcuts, or punish it with the same friction every time?

---

> Tip: "I don't like the colors" is not a heuristic finding. "Aesthetic and minimalist design (#8): the screen shows six competing calls-to-action" is. Always name the number.
