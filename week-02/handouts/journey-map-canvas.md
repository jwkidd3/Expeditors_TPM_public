## The five swim lanes

Fill left-to-right, one column per stage (aim for 5–8 stages).

| Swim lane | What goes here |
|-----------|----------------|
| **1. Stage** | Phases of the journey, named as user tasks (e.g., Arrive at office → Take the day's dispatch → Reconcile) — **not** screen names |
| **2. Actions** | What the user is *doing* — concrete verbs |
| **3. Thoughts** | What they're thinking — 1–2 quotes per stage, using Week-1 interview language where possible |
| **4. Emotions** | Score each stage on a 4-point curve: 😀 → 😐 → 😟 → 😡 (plot it — the curve should not be flat) |
| **5. Touchpoints / friction** | Every system or person the user interacts with — your product, **paper, phone, other software, manager, customer** — and ⭐ the friction |

### What "good" looks like

- The emotions curve is **not flat** — a flat curve usually means the journey has been sanitized. Re-anchor on real interview quotes.
- Friction ⭐ clusters at **2–3 stages**, not 8. If everything is friction, nothing is.
- Touchpoints include **non-product** systems (paper, phone). These are the input to Week 4's system-components mapping — don't lose them.
