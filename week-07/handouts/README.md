# Week 7 Handouts — Agile Delivery & Azure DevOps

Participant-facing handouts extracted from the Week 7 activity packets (Delivery Plan / DP build). Each is a standalone card, template, pack, prompt, or rubric — distribute (print or share) before the day and activity that uses it. Templates and cards are meant to be filled in; answer keys stay in the facilitator lab files, not here.

|---|---|---|
| `output-outcome-sort-pack` | Day 1 · A1 | 12 statements to sort as Output / Outcome / Both / Neither — no answer key |
| `outcome-map-template` | Day 1 · A2 | Fill-in DP Section 1 outcome map (primary / supporting / counter / not-claims) |
| `agile-values-tradeoff-scenarios` | Day 1 · A3 | Four trade-offs to run through the Agile Manifesto values |
| `outcome-map-cross-review-questions` | Day 1 · A4 | Four reviewer questions + optional AI sanity-check prompt |

| `ado-saved-queries` | Day 2 · A3 | The 5 WIQL queries every team needs, ready to paste |
| `standup-prep-prompt` | Day 2 · A4 | AI prompt that turns yesterday's ADO activity into a 5-bullet standup |
| `output-outcome-leading-indicator-triples` | Day 3 · A1 | Fill-in tracking table (output / outcome / leading indicator) + sample |
| `sprint-review-template` | Day 3 · A2 | 6-section sprint review with an outcome slot + leading-indicator dashboard |
| `monthly-outcome-review-template` | Day 3 · A3 | Monthly "is the feature winning?" review + quarterly NS roll-up companion |
