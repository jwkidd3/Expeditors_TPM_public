# Problem Statement Template

> **Day 5 · Activity 1 handout.** One line at a time. **Do not skip "Success looks like."** Every claim in "We know this because" must be tagged by evidence tier (Observed / Reported / Inferred / AI-generated).

---

# Problem statement — [short handle]

**Who** — [persona role + context]

**Currently** — [observed behavior, with frequency]

**Which causes** — [measurable consequence]

**Because** — [root cause, from 5 Whys]

**We know this because** — [evidence, tagged by tier]

**Success looks like** — [the change we'd see if the problem is solved]

---

### The bar to clear
A senior engineer should be able to **scope from this without a clarifying call.** If any line is vague or secretly proposes a solution, rewrite it.
